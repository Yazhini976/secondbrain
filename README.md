# Second Brain

## Description
A private personal vault and financial intelligence application designed to help people organize important personal information, understand their financial situation, manage multiple financial goals, detect conflicts between those goals, and explore possible plans.

## Current status
Project initialization.

## Development approach
The application will be developed incrementally, one verified step at a time.

## Important product principles
- Privacy first
- User control
- Simple experience
- Purposeful design
- Reliable financial calculations
- No unnecessary complexity
